fix(verify): 覆盖判据按发送者排除 —— 修复覆盖率恒为 0

问题：覆盖率实测恒为 0%（最差水位 498307 / 服务端位置 498308，只差 1），
且 recvMs 恒为 30148ms（吃满收尾超时）。

根因：发送者本人拿不到自己那条消息的信号（扇出时按设计剔除 senderId）。
所以每个会话对「自己发的最后一条」永远差一格，而我当时取的是
「所有会话水位的最小值」—— 谁发了最后一条，谁就把最小值拉低 1，判据永远不成立。

修复：判据带上「谁发的」这个信息。
- maxSentIdByGroup 改为 maxSentByGroupSender：群 -> 发送者 -> 最大消息 id
- 每个用户的目标水位 = 该群里「不是他发的」消息的最大 id
- 逐人比对，而不是取全局最小值
- coverageDetail 改为输出 会话数/最差水位/最大目标/最大缺口

实测（万人群 1000 在线）：
  覆盖率        0% -> 100%
  recvMs        30148ms(超时) -> 8817ms
  全程          45.3s -> 9.6s
  会话数=1000, 最大缺口=0

！重要：修复前合流轮次的 recvMs 全部被虚增了 30s，那些数字不可引用。
